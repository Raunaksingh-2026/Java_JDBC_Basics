SQL Categories ->
    1. DDL (Data Definition Language) -> Used to define database structure
           --> CREATE, ALTER, DROP, TRUNCATE, RENAME
    2. DML (Data Manipulation Language) -> Used to modify data
           --> INSERT, UPDATE, DELETE
    3. DQL (Data Query Language) -> Used to retrieve data
           --> SELECT
    4. DCL (Data Control Language) -> Used to control permissions
           --> GRANT, REVOKE
    5. TCL (Transaction Control Language) -> Used to manage transactions
           --> COMMIT, ROLLBACK, SAVEPOINT

JDBC [ Java Data Base Connectivity ] -> USE to connect Database
    Requirement -> 1. MySQL
                   2. JDBC Driver[ .jar ]
    -> found in [java.sql]

    Class/Interface     	Work
1.    DriverManager	        Connection create
2.    Connection	        DB connection
3.    Statement	            SQL execute
4.    PreparedStatement	    Parameterized query
5.    ResultSet	            Data fetch

Flow OF JDBC ->
    Create Database using MySql Workbench --> [ CREATE DATABASES Database_name ] -> [ USE Created_Database_Name ] -> Create Table using Query
       ↓
    Add JDBC Driver [ .jar ] in External library
       ↓
    Import in Java file --> [ java.sql ] package
       ↓
    Load & Register Driver : Act as Translator Between Java and MySQL -> [ // JDBC URL Format -> jdbc:mysql://host:port/database_name ]
       ↓
    Create Connection
       ↓
    Create Statement
       ↓
    Execute Query
       ↓
    Process Result
       ↓
    Close Connection
