SQL Categories ->
    1. DDL (Data Definition Language) -> Used to define database structure
           --> CREATE, ALTER, DROP, TRUNCATE, RENAME
    2. DML (Data Manipulation Language) -> Used to modify data
           --> INSERT, UPDATE, DELETE
    3. DQL (Data Query Language) -> Used to retrieve data
           --> SELECT
    4. DCL (Data Control Language) -> Used to control permissions
           --> GRANT, REVOKE
    5. TCL (Transaction Control Language) -> Used to manage transactions
           --> COMMIT, ROLLBACK, SAVEPOINT

JDBC = Java Database Connectivity
    Purpose:
        -> Connect Java Application with Database
        -> Execute SQL Queries
        -> Retrieve and Manipulate Data
    Requirements:
        1. Database Server (MySQL)
        2. JDBC Driver (.jar)
        3. java.sql package
    MySQL Driver -> [ com.mysql.cj.jdbc.Driver ]
    Older Driver -> [ com.mysql.jdbc.Driver ]
-----------------------------------------------------------------------------

Important JDBC Classes / Interfaces ->
    1. DriverManager
       -> Establishes database connection
    2. Connection
       -> Represents connection with database
    3. Statement
       -> Executes static SQL queries
    4. PreparedStatement
       -> Executes parameterized queries
       -> Prevents SQL Injection
       -> Faster than Statement
    5. CallableStatement
       -> Executes Stored Procedures
    6. ResultSet
       -> Stores data returned by SELECT query
    7. ResultSetMetaData
       -> Information about columns
    8. DatabaseMetaData
       -> Information about database
-----------------------------------------------------------------------------

JDBC Architecture ->
        Java Application
                ↓
            JDBC API
                ↓
           JDBC Driver
                ↓
            Database

JDBC URL Format --> [ jdbc:mysql://host:port/database_name ]
    Example -> [ jdbc:mysql://localhost:3306/learnJava ]
        host          -> localhost
        port          -> 3306
        database_name -> learnJava
-----------------------------------------------------------------------------

JDBC Flow ->
    1. Create Database
    2. Create Table
    3. Add JDBC Driver
    4. Import java.sql package
    5. Load Driver
    6. Create Connection
    7. Create Statement / PreparedStatement
    8. Execute Query
    9. Process Result
    10. Close Resources
--------------------------------------------------

Step 1 : Load Driver -->
       Class.forName("com.mysql.cj.jdbc.Driver");

Note -> Modern JDBC automatically loads driver.
     -> Class.forName() is generally optional.
--------------------------------------------------

Step 2 : Create Connection -->
    Connection con =
        DriverManager.getConnection(
            url,
            username,
            password
        );

    -> Connection is an Interface.
--------------------------------------------------

Step 3 : Create Statement -->
    Statement st = con.createStatement();

    -> Used for static queries.
    -> Example --> [ SELECT * FROM users ]
--------------------------------------------------

Step 4 : Create PreparedStatement -->
    PreparedStatement ps =
        con.prepareStatement(query);

    Advantages ->
        ✓ Faster
        ✓ Reusable
        ✓ Secure
        ✓ Prevents SQL Injection
    Example ->
        -> [ INSERT INTO users(name,email) VALUES(?,?) ]

Step 5 : Execute Query --> SELECT Query
    ResultSet rs =
        ps.executeQuery();

    --> Returns -> ResultSet Object
            INSERT / UPDATE / DELETE

    int rowsAffected =
        ps.executeUpdate();

    --> Returns ->
            Number of affected rows

ResultSet -> is used to read data returned by SELECT query.
    Example ->
        ResultSet rs = ps.executeQuery();
        while (rs.next()) {
            int id = rs.getInt("id");
            String name = rs.getString("name");
            System.out.println(id + " " + name);
        }
    Common methods ->
        rs.next() -> Moves to next row.
        rs.getInt() -> Gets integer value.
        rs.getString() -> Gets String value.
        rs.getDouble() -> Gets double value.
-----------------------------------------------------------------------------

Statement -> | ✓ Simple | ✗ Slow | ✗ SQL Injection Risk |
PreparedStatement -> | ✓ Secure| ✓ Faster | ✓ Reusable | ✓ Industry Standard
-----------------------------------------------------------------------------

SQL Injection -> is a security problem caused by directly putting
user input inside an SQL query.

    Unsafe Example ->
        String query =
            "SELECT * FROM users WHERE name = '" + name + "'";
    Solution ->
        Use PreparedStatement.

    Example ->
        String query =
            "SELECT * FROM users WHERE name = ?";
        PreparedStatement ps =
            con.prepareStatement(query);
        ps.setString(1, name);
